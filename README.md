# 📊 Mobile Sales Dashboard

## 🚀 Overview
This project presents an interactive Mobile Sales Dashboard built using Power BI. It transforms raw sales data into meaningful insights through intuitive and visually appealing reports.

The dashboard helps users monitor performance, identify trends, and make data-driven decisions across time, geography, and product categories.

---

## 🎯 Objective
- Track overall sales performance using key KPIs  
- Analyze monthly and quarterly sales trends  
- Compare current performance with previous year  
- Understand customer purchasing behavior  

---

## 💡 Solution
An interactive Power BI dashboard that:
- Consolidates sales data into a single view  
- Provides real-time filtering and drill-down capabilities  
- Highlights key KPIs and trends  
- Enables Year-over-Year (YoY) comparison  

---

## 🛠️ Tech Stack
- **Power BI** – Dashboard & Visualization  
- **Power Query** – Data Cleaning & Transformation  
- **DAX** – KPIs and Time Intelligence (MTD, YoY)  
- **Excel / CSV** – Data Source  

---

## 📂 Dataset
The dataset includes:
- Date (Year, Quarter, Month, Day)  
- Mobile Brand & Model  
- Sales Amount  
- Quantity Sold  
- Payment Method (UPI, Credit Card, Debit Card, Cash)  
- Customer Ratings  
- Location (City-wise sales)  

---

## 📈 Key KPIs
- Total Sales  
- Total Quantity  
- Total Transactions  
- Average Sales  

---

## ✨ Features
- Interactive dashboard design  
- Time-based filters (Year, Month, Quarter)  
- Same Period Last Year (YoY) comparison  
- Monthly & Quarterly trend analysis  
- City-wise sales visualization (map)  
- Brand & model performance insights  
- Payment method analysis  
- Customer rating breakdown
